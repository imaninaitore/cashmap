# CashMap

CashMap is a modern finance and budgeting web application designed to help users track expenses, manage budgets, and visualize spending habits with ease.

Additional features such as goal setting , savings plan and mentorship programs are inclusive in the web page.

## Features

- Expense tracking interface
- Budget management layout
- Financial summary sections
- Responsive dashboard

## Technologies Used

- HTML5
- Tailwind CSS
